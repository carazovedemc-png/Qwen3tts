# Mia ai voice — что внутри
Новый интерфейс (Compose, без Material), пиксельное небо с кометами, стеклянная панель-линза, листы настроек,
стартовый экран, очередь, экспорт WAV/OGG/M4A, локальный API с редактируемыми адресом/портом/ключом/голосом/языком,
работа в фоне, настройки генерации (temperature/top-p/top-k/repetition/seed) через JNI, выбор CPU/GPU.

## v4 (замер скорости, без изменения интерфейса)
- ggml CPU теперь собирается с -march=armv8.2-a+dotprod+fp16 (раньше без флагов = базовый armv8-a). Меняется свойством qwen.armArch.
- Включены подробные таймеры этапов генерации движка (QWEN3_TTS_TIMING), stderr движка перехватывается в logcat и в приложение.
- Настройки → «Монитор скорости»: время до первого куска, полное время, длительность аудио, RTF, потоки, память, возможности CPU, отчёт движка.
